# SpendWise-
Money tracker webpage 
The money-tracking website works like a personal finance dashboard:

Dashboard – Shows your current balance, total income, total expenses, and recent transactions.
Add Income – You enter an income amount, category/source, date, and description. It increases your balance.
Add Expense – You enter an expense amount and details. It decreases your balance.
Transaction History – All income and expenses are displayed so you can see where your money is going.
Categories – Expenses can be grouped into categories such as Food, Travel, Shopping, Bills, etc.
Calculations – The website automatically calculates:
Balance = Total Income − Total Expenses
Data Storage – Transactions are stored in the browser, so refreshing the page doesn't normally erase your records.
Responsive UI – The interface is designed to work on both desktop and mobile screens.
Simple workflow

Add transaction → Save it → Website updates balance → Transaction appears in history → Dashboard reflects the changes.

So essentially, it acts like a digital personal expense diary + financial dashboard.
